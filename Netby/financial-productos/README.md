# Aplicacion para la gestion de productos con transacciones

## Requisitos
> Para la utilizacion del proyecto se necesita crear la base de datos "bd_ProductosFinancieros"
El script se llama ScriptBD.sql y contiene valores iniciales para la base de datos.

> Ejecutar localmente el proyecto ApiProductos (backend) realizando la configuracion del appSettings
la cadena de conexion "productoFinancieroConnectionString"

> Realizar la instalacion en el proyecto front de las librerias con  npm install, si al instalar las dependencias 
da error utilizar la instruccion npm install --legacy-peer-deps
> Ejecutar el proyecto con ng serve -o  o con ng serve
